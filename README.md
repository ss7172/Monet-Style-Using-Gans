# Instructions on how to run the code
Due to the size of the dataset and generated images, we did not include them inside this project directory.

For DCGAN, run data_agument.py on DCGAN/data. It created a dataset called "augmented_images". Create a folder called "DCGAN/dataset" and move "augmented_images" under this folder "DCGAN/dataset". The folder DCGAN contains a notebook called "DCGAN.ipynb". You can directly run it as the variables have been initialized accordingly.

CycleGAN.ipynb runs on Google Colab and the dataset was stored in Google Drive. To run this notebook, you can choose to either move the dataset to your own Google Drive without changing any code or download the dataset from https://drive.google.com/drive/folders/1vRKhb8ApjFsoAybFT_5Ve8PFbo4rgHhz?dmr=1&ec=wgc-drive-hero-goto and change the paths accessing the dataset to the local directory. The latter option means changing all paths in the form "/content/drive/MyDrive/gan-getting-started/..." to "../data/...". In particular, you can change the paths as follows:
- monet_tfrec = tf.io.gfile.glob('/content/drive/MyDrive/gan-getting-started/monet_tfrec/*.tfrec') -> monet_tfrec = tf.io.gfile.glob('../data/monet_tfrec/*.tfrec')
- photo_tfrec = tf.io.gfile.glob('/content/drive/MyDrive/gan-getting-started/photo_tfrec/*.tfrec') -> photo_tfrec = tf.io.gfile.glob('../data/photo_tfrec/*.tfrec')
- monet_jpg = tf.io.gfile.glob('/content/drive/MyDrive/gan-getting-started/monet_jpg/*.jpg') -> monet_jpg = tf.io.gfile.glob('../data/monet_jpg/*.jpg')
- photo_jpg = tf.io.gfile.glob('/content/drive/MyDrive/gan-getting-started/photo_jpg/*.jpg') -> photo_jpg = tf.io.gfile.glob('../data/photo_jpg/*.jpg')
- output_dir = "/content/drive/MyDrive/GeneratedMonetPainting7038" -> output_dir = "./cyclegan_generated_images"

NST_500.ipynb and NST_1000.ipynb, just like CycleGAN.ipynb, runs on Google Colab and the dataset was stored in Google Drive. To run this notebook, you can choose to either move the dataset to your own Google Drive without changing any code or download the dataset from https://drive.google.com/drive/folders/1vRKhb8ApjFsoAybFT_5Ve8PFbo4rgHhz?dmr=1&ec=wgc-drive-hero-goto and change the paths accessing the dataset to the local directory. The latter option means changing all paths in the form "/content/drive/MyDrive/Applied ML/data/..." to "../data/...". In particular you can change the paths as follows:
- content_folder_path = "/content/drive/MyDrive/Applied ML/data/photo_jpg" -> content_folder_path = "../data/photo_jpg"
- style_folder_path = "/content/drive/MyDrive/Applied ML/data/monet_jpg" -> style_folder_path = "../data/monet_jpg"
- generated_images_path = "/content/drive/MyDrive/Applied ML/data/stylized_jpg_ver4" -> generated_images_path = "./NST_generated_images"


To run CycleGAN+LSGAN_LOSS.ipynb, if you choose not to move dataset to your own Google Drive, in addition to downloading the dataset from https://drive.google.com/drive/folders/1vRKhb8ApjFsoAybFT_5Ve8PFbo4rgHhz?dmr=1&ec=wgc-drive-hero-goto, also download the Berkeley's dataset from https://www.kaggle.com/datasets/dimitreoliveira/monet-paintings-jpg-berkeley/data. Change the paths as follows:
- MONET_DIR = "./monet_jpg/*.jpg" -> MONET_DIR = "../data/monet_jpg/*.jpg"
- BERKELEY_DIR = "./berkeley_monet/*.jpg" -> BERKELEY_DIR = "../data/berkeley_monet/*.jpg"
- PHOTO_DIR = "./photo_jpg/*.jpg" -> PHOTO_DIR = "../data/photo_jpg/*.jpg"
- output_dir = "./generated_images" -> output_dir = "./cyclegan_lsgan_generated_images"

# Folder hierarchy
Under the project directory, we have four folders. 
- The folder "DCGAN" contains code files for DCGAN and a folder "generated_image_fid" containing five sample images generated by DCGAN. It also contains a folder "data" containing the original dataset used for data augmentation.
- The folder "CycleGAN" contains a code file for CycleGAN and a folder "cyclegan_generated_images" containing five sample images generated by CycleGAN.
- The folder "CycleGAN+LSGAN" contains a code file for CycleGAN with LSGAN loss and a folder "cyclegan_lsgan_generated_images" containing five sample images generated by CycleGAN with LSGAN loss.
- The folder "NST" contains code files for NST and a folder "NST_generated_images" containing five sample images generated by NST.
